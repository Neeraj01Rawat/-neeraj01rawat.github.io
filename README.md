# Neeraj Singh Rawat — Data Analyst Portfolio

This is a static personal portfolio website for GitHub Pages.

## Files

- `index.html` — page structure and content
- `style.css` — responsive styling

## Before publishing

Replace these placeholders in `index.html`:

- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN/`

Also replace the generic GitHub link on the UPI project with the actual repository URL once that repository exists.

## GitHub Pages

Create a repository named:

`neeraj01rawat.github.io`

Upload `index.html` and `style.css`, then go to:

Repository → Settings → Pages → Deploy from a branch → `main`

Your site should be available at:

`https://neeraj01rawat.github.io`
